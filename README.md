# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/kskreddy2k7/kskreddy.git
```

---

## Install Dependencies

```bash
npm install
```

---

## Start Development Server

```bash
npm run dev
```

---

## Build Project

```bash
npm run build
```

---

## Preview Production Build

```bash
npm run preview
```
